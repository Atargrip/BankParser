## BankParsers

# Задача - разработать парсеры для нескольких банков
Все парсеры должны возвращать одинаковые структурированные данные в едином формате.

# Структура работы
- Все задачи записываются в issues для отслеживания работы. 
- Для каждой задачи(в данном случае для каждого парсера банка) открывается своя ветка из main с соответствующим названием.
- На своей ветке пишется код, не изменяющий общие файлы, чтобы не было несостыковок.
- По завершении работы отправляется PR (pull request). Изменения мерджатся только если 2 разработчика подтверждают PR.
(последний шаг можно скипнуть на данный момент, задача не сложная, ничего не должна сломать. Но в более сложных проектах этот шаг лучше не пропускать)
